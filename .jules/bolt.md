## 2024-05-18 - [Optimization Constraints]
**Learning:** Adding required comments about optimizations (`✅ Always do: ... Add comments explaining the optimization`) is critical for PR reviews to succeed fully and satisfy constraints. It's not enough to just optimize the code.
**Action:** Ensure that for every performance optimization implemented, clear explanatory comments (e.g., `// ⚡ Bolt Performance Optimization: ...`) are added to the code alongside the changes before requesting a review.
