## 2024-11-20 - Consolidating Multiple Array Reduces
**Learning:** In the `AdminDashboard.jsx`, the original implementation used `orders.filter(...).reduce(...)` three separate times to calculate total revenue, commission, and GST. This meant the `orders` array was being iterated multiple times. While React's `useMemo` is generally helpful for expensive calculations, the structure itself was inefficient.
**Action:** Replaced the three separate `filter().reduce()` operations with a single `reduce` operation that returns an accumulator object containing all three calculated values, wrapped in a `useMemo`. This pattern (reducing once and accumulating multiple values) significantly improves performance by reducing array iterations, especially on large datasets. Use this object accumulator pattern with `useMemo` when calculating multiple derived metrics from a single source array.
