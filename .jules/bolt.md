## 2024-06-25 - React.useMemo for derived array state
**Learning:** In React components like `ProductsPage`, failing to wrap derived array calculations (like `filteredProducts`) in `useMemo` is a significant anti-pattern. Because `ProductsPage` has local state like `sidebarOpen` that triggers a re-render when toggled, every render was causing the entire `products` array to be re-filtered and re-sorted, leading to poor UI performance. Furthermore, repeatedly calling `.toLowerCase()` on invariant string values inside `.filter()` loops introduces massive overhead.
**Action:** Always wrap expensive derived state (especially filtering and sorting large arrays) in `useMemo`. Additionally, extract any invariant transformations (like lowercasing search queries or categories) outside of loops to minimize per-item processing overhead.
