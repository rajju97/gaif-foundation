## 2024-11-20 - Missing Memoization in Product Listing
**Learning:** Found a performance bottleneck in `ProductsPage.jsx` where the entire `products` array was being filtered and sorted synchronously on every render. Given this is an e-commerce platform that will likely have a growing product catalog, this O(n log n) operation blocking the main thread during component updates (like typing in a search input) is an anti-pattern for this specific codebase's catalog view.
**Action:** Wrapped the filtering and sorting operation in `useMemo` with dependencies on `[products, searchQuery, selectedCategory, sortBy]`. This ensures the expensive calculation only runs when the underlying data or filter criteria actually change, preventing unnecessary re-calculations on unrelated state updates.
