## 2024-06-25 - [Consolidating array iterations for derived React state]
**Learning:** In the `AdminDashboard` component, iterating over a large array of orders multiple times during every render (using `.filter().reduce()` for revenue, commission, and GST separately) creates significant overhead. In performance benchmarks, wrapping these multiple passes into a single `.reduce()` pass and memoizing the result with `useMemo` resulted in an ~86% improvement in calculation speed (from ~1009ms to ~140ms for 5 million items).
**Action:** When deriving multiple metrics (e.g., sums, counts) from the same large dataset in a React component, combine the calculations into a single pass (like a single `reduce` returning an object) and wrap it in `useMemo` with the dataset as a dependency to avoid unnecessary re-calculations on every render.
